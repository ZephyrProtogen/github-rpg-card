## 🚀 How to Add to Your Profile

1. Visit the [Live Generator App](https://github-rpg-card.github-rpg-card.workers.dev).
2. Type your GitHub username and select your favorite theme (Cyberpunk, Matrix, or Dracula).
3. Click the **Copy Code** button.
4. Paste the snippet into your GitHub profile `README.md` file (the repository named `your-username/your-username`).
